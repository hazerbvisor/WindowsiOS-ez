| 4. Stabilization | Linux tests cover configuration, state recovery, media validation, firmware, GPT, FAT32, exFAT, WIM modification, driver preflight and artifacts. Twenty-five Linux tests passed, covering nine Swift foundation groups, a 2.25 GiB streaming ISO import with original SHA-256 preserved, writable independent NVRAM and bundled resource checks. The bundled firmware banks booted a generated ARM64 EFI fixture in local QEMU. The NetKVM catalog was verified against its pinned Microsoft signer. The media tests cover UDF, Joliet and ISO9660 fixtures, multi-extent files copied to exFAT, and WinPE preparation. The genuine Microsoft Windows 11 IoT Enterprise LTSC 2024 ARM64 ISO reproduced the original libudfread rejection. The pinned upstream parser opened the disc, confirmed build 26100 and prepared its real boot.wim. The test also confirmed rejection before parsing when given Microsoft’s mismatched published checksum. Full Windows Setup remains pending on iPad. Tests exercised TPM2 startup and random commands with libtpms, state persistence and corruption handling, firmware table emission, and disarming unattended Setup when a disk already has data. The firmware validator also accepted the code and Microsoft-enrolled variable-store headers from Debian’s AAVMF package. The guest session also has a system paste action for single-line keyboard text. Native SwiftUI and Objective-C iOS compilation, device input and bidirectional clipboard are unverified. The upstream core tests compiled their C classification object and then stopped at Apple ARM64 assembly on the x86-64 host.

The first reported Codemagic build stopped during OpenSSL compilation because the generated headers were missing. The dependency script now generates them before building the crypto archive. The next reported Xcode 27.2 run built the native dependencies and stopped compiling the ISO reader and SHA-256 helper because Darwin hides `O_NOFOLLOW` in strict POSIX mode. Both files now request Darwin interfaces on Apple targets and keep symlink rejection. An ARM64 iOS preprocessor probe checked Apple's public header condition, and Linux regression tests checked that hashing and installer preparation reject ISO symlinks. A complete Xcode build and an iPadOS 27.0.1 picker and Setup pass remain pending.
